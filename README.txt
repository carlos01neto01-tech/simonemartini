Estrutura para GitHub Pages:

/index.html
/assets/css/style.css
/assets/img/simone-hero.png
/assets/img/referencia-desktop.png
/assets/img/referencia-mobile.png

Para publicar:
1. Suba todos os arquivos mantendo exatamente essa estrutura.
2. No GitHub, vá em Settings > Pages.
3. Em Branch, selecione main e pasta /root.
4. Salve e aguarde o link do GitHub Pages.
