ARQUIVO PRONTO PARA GITHUB PAGES

Estrutura:
- index.html
- assets/img/simone-desktop.webp
- assets/img/simone-mobile.webp

Como subir:
1. Extraia este ZIP.
2. Suba todos os arquivos para a raiz do repositório no GitHub.
3. O arquivo index.html precisa ficar na raiz, não dentro de uma pasta extra.
4. Ative o GitHub Pages em Settings > Pages > Deploy from a branch > main > root.

Observação:
Não altere o nome da pasta assets nem das imagens, porque o index.html já está configurado para esses caminhos.
